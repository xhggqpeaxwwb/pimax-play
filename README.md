## 🕹️ Overview

Pimax Play is the companion app for Pimax headsets, managing configuration, software updates, the Pimax store, and the PimaxXR OpenXR runtime.

Whether you're a newcomer or a veteran, Pimax Play provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |

| **PimaxXR Runtime** | Native OpenXR runtime bypassing SteamVR for lower latency |
